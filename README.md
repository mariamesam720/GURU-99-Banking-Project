# GURU-99-Banking-Project

##  Project Overview

This project is a **Manual Software Testing project** based on the **Guru99 Banking Application**.

The purpose of the project is to practice the complete manual testing process, including **test case design, functional testing, defect identification, and test reporting**.

##  Testing Objectives

* Verify that the banking application functions according to its expected behavior.
* Identify functional and usability defects.
* Create clear and structured test cases.
* Execute test scenarios and document test results.
* Practice defect reporting using standard QA practices.
* Gain hands-on experience with the **Software Testing Life Cycle (STLC)**.

##  Testing Scope

The following areas of the application were tested:

* Login
* New Customer
* Customer Management
* New Account
* Account Management
* Deposit
* Withdrawal
* Fund Transfer
* Balance Enquiry
* Mini Statement
* Change Password
* Logout

##  Testing Types

* Negative Testing
